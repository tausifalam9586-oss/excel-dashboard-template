# 📊 E-Commerce Sales Analysis Dashboard — Excel

## 📌 Project Overview

This project is an **E-Commerce Sales Analysis Dashboard built using Microsoft Excel**. The main objective of this project is to analyze raw sales data and convert it into meaningful business insights through data cleaning, calculations, PivotTables, PivotCharts, and interactive visualizations.

The dashboard provides a complete overview of **sales performance, product performance, customer behavior, returns, and geographical sales distribution**.

## 🔍 Key Analysis

The project analyzes:

* 💰 Total Sales / Revenue
* 🛒 Total Orders and Quantity Sold
* 📦 Purchase / Cost Analysis
* ↩️ Returned Orders and Return Rate
* 🏆 Top-Selling Products
* 📅 Month-wise Sales Performance
* 📈 Monthly Sales Trends
* 🗺️ State-wise Sales Performance
* 👨‍🦱👩 Gender-wise Shopping Behavior
* 🏷️ Category-wise Sales Performance
* 🔝 Top-Performing Products and Categories
* 📊 Order and Sales Performance
